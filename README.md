 FOCUS X

Take Control of Your Time.

FOCUS X is an Android productivity application designed to help users reduce distractions, manage screen time and improve focus.

🚀 Features

- 📱 App Blocker
- 🌐 Website Blocker
- ⏱️ Focus Timer
- 🔒 Strict Mode
- 📊 Screen Time Tracker
- 📈 Daily & Weekly Reports
- 🎯 Study Goals
- 🌙 Modern Black & Purple UI

🛠️ Technology

- Kotlin
- Android SDK
- Jetpack Compose
- Room Database

📱 Platform

Android

💰 Pricing

Free – No Subscription.
